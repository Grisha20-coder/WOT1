# Семантическое версионирование (SemVer) — стандартизированный способ обозначения версии программного продукта.
MAJOR: крупные изменения API или функциональности, несовместимые с предыдущими версиями (vX.Y.Z → X увеличивается).
MINOR: добавления новых функций, обратносопоставимых с предыдущей версией (vX.Y.Z → Y увеличивается).
PATCH: исправления ошибок и незначительные улучшения (vX.Y.Z → Z увеличивается).
